# Archive

`experiments` contains retained research and sanitized historical source snapshots.
These are references, not production code or current development instructions.
Snapshot contents and their hash manifests are preserved; navigation links in the
archive index follow the current source layout.

Current implementation is under [Development](../Development/README.md). The sole
current continuation is [planning/development.md](../planning/development.md).
Local private evidence, account-bearing material and compiler caches are not
copied into this tracked archive. Machine-local archives stay in workspace/archive.
